This document lists the external resources that are downloaded to construct a reference for the pipeline

# Ontologies

Ontologies are downloaded in OBO format.  The current ontologies used are:
- Disease Ontology (http://disease-ontology.org/)
- Cell Ontology (https://bioportal.bioontology.org/ontologies/CL)
- Uberon (http://uberon.github.io/)
- ChEBI (https://www.ebi.ac.uk/chebi/)
- Experimental Factor Ontology (http://www.ebi.ac.uk/efo/)
- Unit Ontology (https://bioportal.bioontology.org/ontologies/UO)
- Cellosaurus (http://web.expasy.org/cellosaurus/)

# SPECIALIST Lexicon

The following files are used from the SPECIALIST Lexicon:
- LEXICON : https://data.lhncbc.nlm.nih.gov/public/lsg/lexicon/2025/release/LEX_DOC/LEXICON
- LRAGR : https://data.lhncbc.nlm.nih.gov/public/lsg/lexicon/2025/release/LEX_DOC/LRAGR
- LRNOM : https://data.lhncbc.nlm.nih.gov/public/lsg/lexicon/2025/release/LEX_DOC/LRNOM
- LRSPL : https://data.lhncbc.nlm.nih.gov/public/lsg/lexicon/2025/release/LEX_DOC/LRSPL
- LRTRM : https://data.lhncbc.nlm.nih.gov/public/lsg/lexicon/2025/release/LEX_DOC/LRTRM
